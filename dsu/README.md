# disjoint-set union (DSU)
```
    _                                  70]
   [2,          __                 61,
       3,      [21, 34]    __  50,
          5]   _          [42,
              [8, 13]

```

a disjoint set union (DSU), also known as disjoint sets, is, as the name suggests, a union of disjoint sets - sets with no element in common.

## building
```
make dsu_demo
```
builds a program that creates a BST and traverses it using inorder, preorder and postorder traversal.

## structure
- `dsu.c/h` - binary search tree implementation
- `demo.c` - demonstration program
