# binary search trees

```
        [5]
       /   \
    [3]     [8]
   /           \
[2]             [13]
```

it's a binary tree that can be used to search quickly.

## building
```
make bst_demo
```
builds a program that creates a BST and traverses it using inorder, preorder and postorder traversal.

## structure
- `bintree.c/h` - binary search tree implementation
- `demo.c` - demonstration program

## explanation
the binary search tree uses a custom structure called `Node`.
